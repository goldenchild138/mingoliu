# Ming Liu — Portfolio

Static site. No build step.

- `index.html` — the whole site (loads `support.js` and files in `assets/`)
- Open `index.html` locally, or publish with GitHub Pages: repo Settings → Pages → Deploy from branch → `main` / root.

Note: the Synthace video is embedded from YouTube, so it only plays when served over http(s), not from a `file://` path.
